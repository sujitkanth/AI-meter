# AI Meter India

AI-based fair fare calculator for Indian public transport.

## Features
- Input: Name, Vehicle Type, Distance
- Automatically calculates fare using base fares and inflation
- Built with Python + Flask

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the app:
   python ai_meter.py
3. Open browser at http://127.0.0.1:5000/
